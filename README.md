# FedWAM

Anonymous project page for **FedWAM: Federating Predictive World Knowledge for Personalized Robot Control**.

- [Project page](https://submit-anonymous.github.io/FedWAM/)
- [Interactive guide](https://submit-anonymous.github.io/FedWAM/explainer/)
- [Supplementary code](assets/downloads/FedWAM_anonymous_code.zip)

The website is static HTML, CSS and JavaScript. Open `index.html` locally or serve this directory with a static HTTP server. No build step, external fonts, analytics or model inference is required. GitHub Pages serves the `main` branch root.

The seven-chapter guide includes a 4½-minute silent tour, interactive teaching computations, reference evaluation and native-model recordings. Light and dark themes are available; light is the default.

See [acknowledgments](ACKNOWLEDGMENTS.md) and the [media manifest](explainer/assets/evidence.json) for model and recording information.
