# Reference acknowledgments

This implementation was written for FedWAM. The interaction design was informed by the bundled Research Interactive Explainer guide and its D-JEPA and Transformer Explainer references: a stable architecture locator, linked inspection views and a seekable shared timeline. Scientific content, calculations, copy, colors, timing and media were independently adapted to FedWAM. No reference implementation source or example recordings are redistributed in this package.

Research model and benchmark attribution: LaWAM; ImageWAM–FLUX.2–4B; DINOv3; LIBERO and LIBERO-Plus. The media manifest identifies the released native checkpoints used in the recordings. The guide does not redistribute model weights or training datasets.
