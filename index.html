THE IDEA

World knowledge travels.
Controllers stay personal.

Robotic experience is distributed across environments. Each robot learns useful predictions, yet its controller is shaped by its own observations and local experience. FedWAM makes predictive world knowledge the interface for collaboration.

Clients communicate condition–prediction pairs in a shared feature space. The server learns a conditional teacher; each client calibrates how much knowledge to absorb, then adapts its world model and private action expert together. The main study uses LaWAM, with a LaWAM–ImageWAM extension for heterogeneous architectures.

Conditional aggregation

Fit a client-balanced teacher across clients’ local prediction packets. Conditioning preserves which state and context each predicted future belongs to.

Personalized reception

Compare teacher and local errors on held-out calibration data. Weight distillation locally, then adapt the private controller to its updated world features.

What does “future” mean?

The prediction horizon is the end of one action chunk. FedWAM communicates compact future features; a full future video is not required. The local adaptation stage is retained after the final communication round.

HETEROGENEOUS MODEL EXTENSION

Different architectures.
A common predictive language.

LaWAM is the primary model for studying federated world knowledge. ImageWAM–FLUX.2–4B extends the framework to a second architecture through an aligned predictive readout.

Architecture-specific interfaces map control-connected world features to a shared reference space. Teacher supervision returns through the world pathway, while each model retains its native action expert.

EXPERIMENTAL DESIGN

Evaluate knowledge through control.

A unified protocol connects prediction quality, task success, cross-domain transfer, and communication cost.

4visual training domains
7evaluation perturbation categories
40base tasks across four LIBERO suites
2WAM architectures

Transfer across environments

Each recipient is evaluated in lighting, viewpoint, noise, background, object layout, robot initialization, and language conditions. A 4 × 7 matrix separates local specialization from transfer.

Matched comparisons

Local learning, world-parameter sharing, public-query distillation, conditional-teacher sharing, and self-distillation controls use matched local training budgets and data splits.

Mechanism and efficiency

Ablations study future versus transition targets, calibration, final action adaptation, and packet size. Metrics connect prediction error to control success and communication bytes.

Cross-architecture transfer

Same-architecture and cross-architecture donors isolate the value of heterogeneous knowledge. Directional and bidirectional comparisons test both receiver architectures.
